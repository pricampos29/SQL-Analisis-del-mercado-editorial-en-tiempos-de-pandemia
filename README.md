# 📚 Proyecto SQL: Análisis del mercado editorial en tiempos de pandemia
Este proyecto explora el comportamiento de los usuarios/as de una startup enfocada en libros, basada en una base de datos relacionada con información sobre obras, editoriales, autores/as, calificaciones y reseñas.

## 🎯 Objetivo 
Identificar tendencias en la publicación y recepción de libros para generar una propuesta de valor efectiva para un nuevo producto en el sector editorial.

## ⚙️ Metodología
- Se utilizó una base de datos con información sobre libros, editoriales, autores, reseñas y usuarios.
- Se aplicaron consultas SQL para filtrar, agrupar y calcular métricas clave como:
  - Número de libros publicados después del año 2000.
  - Cantidad de reseñas por libro y calificación promedio.
  - Editorial con mayor volumen de publicaciones.
  - Autor con mejor calificación promedio.
  - Promedio de reseñas escritas por usuarios altamente activos (más de 50 libros calificados).

## 📊 Resultados
- **Libros recientes:** 819 títulos fueron publicados después del 1 de enero de 2000, lo que representa una base sólida de contenido moderno.
- **Popularidad y calificaciones:** Algunos libros tienen muchas reseñas (ej. libro 51 con 60 reseñas), y las calificaciones promedio oscilan entre 4.0 y 4.5, indicando buena aceptación general.
- **Editorial líder:** Penguin Books destaca con 42 títulos, mostrando fuerte presencia en el mercado.
- **Autor mejor calificado:** Diana Gabaldon tiene una calificación promedio de 4.3, lo que refleja alta apreciación por parte de los lectores.
- **Usuarios activos:** Aquellos que calificaron más de 50 libros han escrito en promedio 719.76 reseñas de texto, lo que demuestra un alto nivel de participación y generación de contenido.

## 🧾 Conclusiones
- Existe una **oportunidad clara en libros recientes**, con un mercado activo en publicaciones modernas.
- Las **reseñas y calificaciones** son indicadores confiables de calidad para los usuarios.
- **Penguin Books** domina en volumen editorial, lo que puede ser aprovechado para alianzas estratégicas.
- **Autores destacados** como Gabaldon pueden impulsar el éxito de nuevos productos editoriales.
- La **comunidad de lectores activos** valora compartir opiniones, lo que puede ser aprovechado para fortalecer el engagement.

## ✅ Recomendaciones
1. Desarrollar un producto que **resalte libros recientes y mejor calificados**, atrayendo a lectores interesados en contenido moderno.
2. Incorporar **reseñas como guía de calidad**, mejorando la experiencia del usuario.
3. Establecer **colaboraciones con editoriales reconocidas** como Penguin Books para aumentar la credibilidad.
4. Promover obras de **autores con alta reputación**, como Diana Gabaldon, para atraer más lectores.
5. Incentivar la **participación activa de la comunidad**, mediante funciones que valoren y visibilicen las reseñas de usuarios comprometidos.
